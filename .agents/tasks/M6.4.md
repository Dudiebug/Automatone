# M6.4 — Full MVP security, persistence, and failure matrix

## Metadata

- State: PLANNED
- Milestone: M6
- Depends on: INFERRED M6.3 scheduling edge; no explicit task-level dependency
  is stated by the plan.
- Risk: critical
- Sensor profiles: default, architecture_sensitive, runtime_minecraft,
  network_security, persistence
- Approved plan reference: plan lines 784-837.

## Objective

Execute the complete end-to-end MVP matrix for ownership, packets, persistence,
interruption, runtime reconstruction, native/product failures, completion,
cancellation, and excluded-feature absence.

## Why this task exists

This is the final closed-loop product proof. It must combine the server
authority, persistence, restart, typed-failure, and native mining contracts
without allowing a missing sensor or excluded feature to hide an unresolved
failure.

## Allowed scope

- Every security, persistence, interruption, runtime, failure, completion,
  cancellation, and unload case listed in plan lines 786-801.
- Fresh-context execution of the Milestone 6 commands and documented
  dedicated-server/client MVP flow.
- Scope review proving no excluded feature is required.

## Explicitly forbidden / out of scope

- Omitting a matrix case or converting unavailable evidence to PASS.
- Storage automation, chunk loading, work zones, dashboards, multi-worker
  dispatch, scanner enhancements, retries, or offline mining.
- A second scanner, pathfinder, target queue, movement engine, or mining
  algorithm.
- Weakening tests or changing acceptance criteria to hide failure.

The mandatory shared rules are in INDEX.md#global-architecture-contract,
INDEX.md#quantity-semantics, INDEX.md#explicitly-out-of-scope-through-milestone-6,
and INDEX.md#milestone-6-gate.

## Implementation constraints

- Preserve every matrix bullet exactly.
- Run required sensors independently and mark unavailable ones UNVERIFIED.
- Use server-owned state and native Automatone behavior.
- Verify one fresh runtime after reload and no auto-resume.
- No excluded feature may be introduced to make a case pass.
