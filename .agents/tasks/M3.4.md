# M3.4 — Native one-block mining proof

## Metadata

- State: PLANNED
- Milestone: M3
- Depends on: INFERRED M3.3 scheduling edge; no explicit task-level dependency
  is stated by the plan.
- Risk: critical
- Sensor profiles: default, architecture_sensitive, runtime_minecraft
- Approved plan reference: plan lines 434-473.

## Objective

Prove in a dedicated-server GameTest that one direct native MineProcess
mine(targetBlock) call discovers, reaches, faces, and breaks one isolated
normal-hardness target without consumer coordinates or a duplicate engine.

## Why this task exists

This is the first end-to-end product proof. It validates the native discovery
and pathing chain, server-side movement, worker reach/break adaptation, normal
destruction, and cancellation boundary in the real runtime.

The test must be intentionally small and must not smuggle a consumer scanner,
pathfinder, or target queue into the proof. Passing this task is the explicit
gate before GUI work.

## Allowed scope

- One worker, one traversable chamber, and one isolated normal-hardness target
  ore.
- The direct native call worker.getBaritone().getMineProcess().mine(targetBlock).
- Assertions for native discovery, movement, reach/facing, break, and drops.
- Source/architecture review for no custom A*, ore scanner, or target queue.

## Explicitly forbidden / out of scope

- Consumer target coordinates or custom target queues.
- Custom A*, ore scanning, pathfinding, movement, or mining.
- GUI, menu, networking, quantity, persistence, or storage.
- GUI work before this proof and the full Milestone 3 gate pass.
- A native-process test double.

The full global architecture contract, quantity semantics, and excluded-feature
list are preserved in INDEX.md.

   UNKNOWN.

## Implementation constraints

- Call only the native MineProcess API named by the plan.
- Keep target discovery and pathing native.
- Use server-authoritative world mutation and normal drops.
- Repeat in a fresh server context for acceptance.
- No GUI work may start before this gate passes.

## Milestone completion gate

M3 cannot be complete until all of these plan gates pass:

- One direct native mine(block) call finds the target without consumer
  coordinates.
- The worker walks to and faces or reaches it.
- Normal positive-hardness progressive breaking succeeds.
- Normal destruction and drop behavior occurs.
- Mid-break cancel works.
- The consumer has no second mining, search, or pathing engine.
- The mining GameTest passes consistently.

M3.4 is the end-to-end proof task for this gate.
