## Contract

Default scope is all owned active workers across dimensions. Filter by active /
retired / both, dimension and individual worker. Unloaded or pending active
workers appear unavailable; never transfer their saved copies. Include archives,
including saved offhand/armor contents without duplicating the selected main hand.

Group by item and exact components. Present paged item icons and counts, with
hover names/components/source counts. Search names and registry IDs. Preserve
selection across snapshots and page changes; Select all selects every filtered
variant, including offscreen results. Clear removes all selection. Bound client
intents and outgoing pages; the server owns variant identities and selection.

Transfer only capacity that fits into the real player inventory. Protect all
active tools/equipment and up to 64 ordinary cobblestone in each worker. Archives
are fully withdrawable. Never eject, generate, discard or duplicate a remainder.

Collection followed by retirement is optional/off by default. Preview the exact
active workers in the scope (including those with no selected items), confirm
that mining stops, transfer first and then retire all those workers preserving
all overflow/equipment. Validate the server snapshot/token, ownership, inventory
and roster revisions before any mutation. Stale/invalid/repeated requests cannot
transfer or retire. Partial capacity is supported and reports moved/remainder.
