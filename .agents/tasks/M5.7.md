## Astra's focused testing foundation

- Luna owns only WorkerNotificationsGameTest.java; Astra owns production and reviews
  test expectations. Use real ServerLevel/WorkerEntity/native destruction for the
  completion-hook case. Real ServerPlayer/menu/connection objects with a captured
  outbound transport sink are allowed; do not mock authorization, saved records,
  job state, registry lookup, or the completion service.
- A finite real job completes once: owner history contains exactly its run identity,
  worker/name, targets, amount, time and unread state; another owner has no history
  or delivery. Repeated completion calls, snapshots, settings replan, pause/resume
  and server save/load cannot duplicate an already completed run. New runs can add
  one new entry. Unowned, running, cancelled and failed jobs produce no completion.
- Persistence/cap fixture may restore valid completed entity NBT with distinct run
  UUIDs to exercise 101 history entries cheaply; it must not claim those are 101
  native mining proofs. Retain only latest 100 in order, preserve exact records,
  read states, last-notified identity and independent toast/sound preferences after
  SavedData round-trip. Version-one roster files without notification fields use
  empty history and enabled defaults. Stale preference revision rejects unchanged.
- Offline completion still persists. Login sends one unread-count summary and no
  replay of individual completion notices; duplicate login event for the same
  connection does not duplicate it. Logout/reconnect can send one new summary.
  Mark-read and mark-all-read persist and remain owner-scoped through actual menu
  intents. Snapshot paging never exposes another owner and is bounded to five rows.
- Verify toast/sound booleans independently in actual delivery payloads; disabled
  presentation never drops inbox history. Real toast visibility/quiet sound stays
  on the human GPU checklist. Dedicated server must load without client classes.
- Fixture cleanup closes menus, removes only fixture players/workers and restores
  changed state on success/failure. Escalate contradictions or production failures
  to Astra; no production edits, weakened assertions, broad suites or redelegation.
- Focused namespace: automatone_worker_m5_notifications_gametest. Compile/run only
