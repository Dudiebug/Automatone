# M5.11 — Native placement and pickup rules

Status: COMPLETE. Prerequisite M5.10 `fe49af77` COMPLETE.
Authority: `docs/M5_GLOBAL_MANAGEMENT.md`.

## Placement contract

WorkerEntityController must execute actual block-item placement from native
right-click intent, using a non-player placement context and the worker hand.
Enforce same server thread/entity/world, live attached worker, loaded world
bounds, eye reach and actual ray hit/face, allowPlace setting, collision and
NeoForge entity grief/placement cancellation. No FakePlayer or native algorithm
replacement. Server-side successful interaction maps to SUCCESS for native
BlockPlaceHelper. Exactly one block is consumed on success; failure/cancellation
restores inventory/world. Empty or unsupported held items fail without mutation.

## Pickup contract

Always apply 64 ordinary cobblestone working reserve, zero quota for other
ignored blocks; wanted/default nonlisted items can be collected while capacity
allows. Tools/components/explicit target blocks and learned native target drops
are protected. Cobblestone targeted as a job output can exceed 64. No automatic
ejection or deletion of held inventory. Keep old common-block default list.
Worker overrides inherit a personal default list unless explicitly customized.
Migration preserves existing custom lists and all stacks, ignores old Enable/
Keep knobs in favor of the approved always-on fixed policy, and retains target
drop protection. Invalid policy data falls back safely without deleting items.

Public worker configuration becomes applyInventoryManagement(List<BlockId>),
marking an override. Rules snapshots expose Blocks and Override; reserve is fixed
64 (not editable). Personal/default/reset wiring stays in WorkerRoster/menu.

## Acceptance and assignments

- Real native CustomGoalProcess bridge over a forced gap and vertical pillar
  reach the goal using placed cobblestone; world placements equal consumed items.
  Test rejected placement, no blocks, non-owner context/world/reach, denied grief
  and cancelled EntityPlaceEvent preserve world/items. Real blocks/worker/native
  runtime only; outbound transport capture allowed, no mock placement/pathfinder.
- Real pickups at 63/64 reserve, refill after use, reject other ignored blocks,
  accept valuables, protect components and native target drops; no ejection when
  full. Save/load and old-policy migration retain exact contents/custom lists.
- Personal defaults propagate to inheriting active workers, customized workers
  retain overrides, reset resumes defaults and restart/reattachment inherits them.
- Existing controller/menu authorization and payload bounds remain enforced.

Astra owns production and menu-policy regression adjustments. Luna assignments
own only explicitly named placement/cleanup GameTests. Compile/runtime runs are
controller-coordinated to avoid concurrent source writes. Focused checks only;
independent extension gate is PENDING until M5.14.
