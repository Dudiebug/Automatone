# M6.2 — Harden restart and unload semantics

The approved 2026-09-06 chunk-loading addition replaces the original
RUNNING-to-INTERRUPTED/manual-Start rule. Reuse M4.5 measurements where unchanged;
add checks only for M5/M6 integration risks. Never restore A* paths, scanned ore
positions, partial break progress or active process objects. Resume valid saved
RUNNING jobs once their worker and chunks are ready, using fresh native discovery.

Inspect permanent removal, shutdown and dimension transfer independently. Clean
up runtime references at shutdown without erasing saved running intent or valid
center tickets. Death/permanent removal releases tickets. A dimension transfer
moves UUID-owned loading to the new dimension. The server performs no work while
stopped or paused; crash-proof world/entity transactions are outside the MVP.

M6 depends on M5.8 acceptance under docs/M5_GUI_CONTROLLER.md. Include retired
records and reactivation in ownership/ticket lifecycle checks; never recreate an
archived worker or grant equipment while recovering an existing worker.
