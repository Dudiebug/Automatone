# Decision / Blocker Records

Use this directory when implementation evidence disproves an approved assumption or a task requires an architecture decision beyond its authorized scope.

Suggested names:

- `ADR-001-short-title.md` for approved architecture decisions.
- `PROPOSED-M3.2-short-title.md` for an implementation-discovered proposal awaiting approval.
- `BLOCKED-M3.2-short-title.md` for a task that cannot proceed under current assumptions.

A proposal/blocker should include:

1. affected task(s);
2. approved assumption/constraint;
3. observed evidence disproving or challenging it;
4. exact source/runtime references;
5. smallest viable change;
6. alternatives considered;
7. impact on later tasks/milestones;
8. whether any implementation candidate must be discarded.

Implementation agents may create a proposal, but may not treat it as approved.
