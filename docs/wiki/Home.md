# Automatone 1.0

Automatone adds autonomous mining workers to Minecraft 1.21.1. Players supply
tools and materials, configure mining jobs, and manage workers through an
Automatone Controller. Mining and all state changes are controlled by the server.

Version 1.0 ships as one universal JAR for dedicated servers, multiplayer clients,
and singleplayer. Start with [Installation and Upgrades](https://github.com/Dudiebug/Automatone/wiki/Installation-and-Upgrades),
then follow [First Worker](https://github.com/Dudiebug/Automatone/wiki/First-Worker).

## What you can do

- Mine up to 128 target block types with a finite combined quota or Unlimited.
- Manage up to ten active workers per player from anywhere and across dimensions.
- Supply real tools and materials, inspect 36-slot inventories, and collect outputs.
- Pause, resume, stop, relocate, retire, and reactivate workers without losing state.
- Configure personal defaults, per-worker overrides, pickup rules, and notifications.
- Keep running jobs active while the owner is offline, as long as the server is running.
