# Controller sprite

`controller.piskel` is the editable production source, drawn in the Piskel web
editor on 2026-09-06. Its 1x PNG export is shipped at
`worker/src/main/resources/assets/automatone_worker/textures/item/controller.png`.

The single 16x16 transparent frame uses nine colors: dark casing, shaded iron,
green worker display/button and a copper antenna. The approved controller concept
is a visual reference; no ImageGen output is used in this production texture.
Minecraft's generated item model supplies inventory and held-item rendering.
